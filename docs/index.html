Module-based diagrams

The diagram page is a self-contained HTML/SVG artifact with an inspectable data model (ROZETA_MODULE_MODEL). It is easy to embed into a future official website or publish through GitHub Pages.

Tip: keep diagrams vector/HTML-first. Do not replace them with low-resolution PNG exports; users need readable labels and zoomable architecture views.

Included views

  • Module architecture: public headers, implementations, tests, examples.
  • Robotour autonomous loop: GPS + LiDAR + odometry into navigation and motor commands.
  • Data flow: inspectable payload labels such as GPS fix, LiDAR scan, obstacle sectors, pose estimate and motor commands.
